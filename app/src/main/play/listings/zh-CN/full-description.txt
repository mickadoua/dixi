Voxbulle 是一个悬浮气泡，在任何 Android 应用里把你的语音变成文字。

使用方法
1. 点按气泡：它悬浮在其他应用上方。
2. 开口说话。声波随你的声音起伏，每次听写最长 5 分钟。
3. Voxbulle 给出建议文字。点按某个词可以修改，然后确认：文字会被复制（如果开启下面的选项，还会替你粘贴）。

Voxbulle 能做什么
• 一个悬浮在其他应用上方的气泡，一个手势就能隐藏。屏幕边缘的细条或通知可以把它找回来。
• 文字会被整理：加上标点和分段，去掉口头禅。意思不变。
• 支持法语或英语听写。可在两者之间自动识别，也可以在设置里选择语言。
• 保留最近 20 次听写的历史，只存文字。你随时可以清除。
• 无需注册账号。

Mistral 转写，使用你自己的 API 密钥
转写由 Mistral（Voxtral 模型）完成。使用前，你要在 console.mistral.ai 创建自己的 API 密钥，并粘贴到 Voxbulle 的设置里。密钥加密保存在你的手机上。API 的使用费由 Mistral 按其条款收取，不由 Voxbulle 收取。没有密钥时，应用以演示模式运行：只显示示例文字，不发送任何内容。

自动粘贴（可选）
默认关闭。开启后，Voxbulle 使用 Android 的无障碍服务只做一件事：把听写的文字粘贴到你正在输入的输入框。它不会读取你的屏幕内容，也不收集任何数据。不开启此选项时，文字会被复制，由你自己粘贴。

你的数据
• 音频会发送给 Mistral 进行转写。Voxbulle 从不保存音频。
• 最近几次听写的文字保存在你的手机上。
• 你的 API 密钥加密保存在你的手机上。

须知
• 目前应用界面为法语。
• Voxbulle 需要麦克风、网络连接，以及在其他应用上方显示气泡的权限。
