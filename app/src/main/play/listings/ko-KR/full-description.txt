Voxbulle은 어떤 Android 앱에서든 목소리를 글자로 바꿔 주는 플로팅 버블입니다.

사용 방법
1. 버블을 누르세요. 다른 앱 위에 떠 있습니다.
2. 말하세요. 목소리에 맞춰 파형이 움직이며, 한 번에 최대 5분까지 받아쓸 수 있습니다.
3. Voxbulle이 글자를 제안합니다. 단어를 눌러 고친 뒤 확인하면 글자가 복사됩니다. 아래 옵션을 켜면 대신 붙여 넣어 줍니다.

Voxbulle이 하는 일
• 다른 앱 위에 떠 있는 버블. 동작 한 번으로 숨길 수 있고, 화면 가장자리의 띠나 알림으로 다시 불러옵니다.
• 글자를 다듬습니다. 문장 부호와 문단을 넣고 군말을 없앱니다. 뜻은 바뀌지 않습니다.
• 프랑스어 또는 영어로 받아쓰기. 둘 사이를 자동으로 감지하거나 설정에서 언어를 고를 수 있습니다.
• 최근 20번 받아쓰기 기록을 글자만 저장합니다. 언제든 지울 수 있습니다.
• 계정을 만들 필요가 없습니다.

Mistral 전사, 내 API 키로
전사는 Mistral(Voxtral 모델)이 처리합니다. 사용하려면 console.mistral.ai에서 내 API 키를 만들어 Voxbulle 설정에 붙여 넣으세요. 키는 휴대폰에 암호화되어 저장됩니다. API 사용 요금은 Voxbulle이 아니라 Mistral이 자체 약관에 따라 청구합니다. 키가 없으면 앱은 데모 모드로 작동합니다. 예시 글자만 나오고 아무것도 전송되지 않습니다.

자동 붙여넣기(선택)
기본값은 꺼짐입니다. 켜면 Voxbulle은 Android 접근성 서비스를 한 가지 용도로만 사용합니다. 받아쓴 글자를 입력 중인 칸에 붙여 넣는 것입니다. 화면 내용을 읽지 않으며 데이터를 수집하지 않습니다. 이 옵션을 켜지 않으면 글자가 복사되고, 직접 붙여 넣으면 됩니다.

내 데이터
• 오디오와 전사된 텍스트는 전사를 위해 Mistral을 거칩니다. Voxbulle은 오디오를 저장하지 않습니다.
• 최근 받아쓰기의 글자는 내 휴대폰에 남습니다.
• API 키는 내 휴대폰에 암호화되어 남습니다.
