Dixi فقاعة عائمة تحوّل صوتك إلى نص في أي تطبيق على Android.

كيف يعمل
1. المس الفقاعة: تطفو فوق تطبيقاتك الأخرى.
2. تحدّث. تتحرك الموجة مع صوتك، حتى 5 دقائق في كل إملاء.
3. يقترح Dixi النص. المس كلمة لتصحيحها ثم أكّد: يُنسخ النص (ويُلصق لك إذا فعّلت الخيار أدناه).

ماذا يفعل Dixi
• فقاعة فوق تطبيقاتك الأخرى، تخفيها بحركة واحدة. يعيدها شريط عند حافة الشاشة أو إشعار.
• يُرتَّب النص: علامات الترقيم والفقرات، وتُحذف كلمات التردد. لا يتغير المعنى.
• الإملاء بالفرنسية أو الإنجليزية. كشف تلقائي بينهما، أو اختر اللغة من الإعدادات.
• سجل لآخر 20 إملاءً، نصوص فقط. تمسحه متى شئت.
• لا حاجة إلى إنشاء حساب.

النسخ بواسطة Mistral، بمفتاح API الخاص بك
يتولى Mistral النسخ (نموذج Voxtral). لاستخدامه، تنشئ مفتاح API خاصًا بك على console.mistral.ai وتلصقه في إعدادات Dixi. يبقى المفتاح مشفّرًا على هاتفك. تحاسبك Mistral على استخدام API وفق شروطها، وليس Dixi. بدون مفتاح يعمل التطبيق في وضع العرض التجريبي: نص تجريبي ولا يُرسَل شيء.

اللصق التلقائي (اختياري)
معطّل افتراضيًا. إذا فعّلته، يستخدم Dixi خدمة الأدوات المساعدة (إمكانية الوصول) في Android لغرض واحد فقط: لصق النص المُملى في الحقل الذي تكتب فيه. لا يقرأ محتوى شاشتك ولا يجمع أي بيانات. بدون هذا الخيار يُنسخ النص وتلصقه بنفسك.

بياناتك
• يمرّ الصوت والنص المحوَّل عبر Mistral لتحويل الكلام إلى نص. لا يحتفظ Dixi بالصوت أبدًا.
• يبقى نص آخر إملاءاتك على هاتفك.
• يبقى مفتاح API على هاتفك، مشفّرًا.
